# LotLink

**Find. Verify. Buy.**  
Global public surplus research & discovery service.

LotLink researches and verifies legitimate government and institutional surplus opportunities worldwide. Clients receive clear, human-reviewed reports and purchase directly from the official seller.

## Live site
- Production: https://lotlink-gules.vercel.app/
- This repository is the Phase 1 functional upgrade.

## Features in this version
- Multi-language ready (EN / FR / PT)
- Research Request form
- Sample report page
- Official Sources directory
- API endpoint for form notifications (Discord webhook)
- Softened professional dark theme

## Local development
```bash
npm install
npm run dev
```

## Environment variables (Vercel)
- `DISCORD_WEBHOOK_URL` – receives new research requests

## Pricing (launch)
- Standard Verified Report: $199
- Priority Report (24h): $349

## Principle
We never sell the asset. We never take possession. We charge for research and verification only.
